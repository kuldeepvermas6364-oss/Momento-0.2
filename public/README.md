# Public Assets

This folder contains static assets served directly by Next.js.

## Structure

- `/public/assets/` - images, icons, logos
- `/public/favicon.ico` - site favicon
- `/public/robots.txt` - search engine directives
- `/public/manifest.json` - PWA manifest

## Notes

Place any static images, fonts, or downloadable files here.
These are accessible at the root URL (e.g. `/assets/logo.png`).
